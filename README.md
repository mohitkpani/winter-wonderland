## About the Project

Winter Wonderland is an interactive Christmas-themed website developed using React and Vite.

The website brings the magic of Christmas to life with a beautiful winter atmosphere, an interactive Santa village, a decorated Christmas tree, animated snowfall and a festive comic-style story.

## Features

- **Magical Home Page** – A beautiful Christmas-themed landing page.
- **Santa's Village** – Explore a magical winter village.
- **Interactive Christmas Tree** – Experience a beautifully decorated Christmas tree.
- **Santa's Story** – Discover Christmas through comic-style chapters.
- **Animated Snowfall** – Enjoy falling snow throughout the website.
- **Background Music** – Magical background music for a festive atmosphere.
- **Responsive Design** – Supports desktop, tablet and mobile devices.
- **Smooth Navigation** – Navigate between pages using React Router.

## Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/mohitkpani/winter-wonderland.git
```

### 2. Open the project directory

```bash
cd winter-wonderland
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### 5. Build for production

```bash
npm run build
```

The production files will be generated inside the `dist` directory.

## Deployment

This project can be deployed using **Cloudflare Pages** through GitHub integration.

| Configuration          | Value           |
| ---------------------- | --------------- |
| Framework preset       | Vite            |
| Production branch      | main            |
| Build command          | `npm run build` |
| Build output directory | `dist`          |
| Root directory         | `/`             |

Every new push to the connected GitHub branch can trigger an automatic deployment.
