## 🌟 Welcome to Winter Wonderland!

Step into a magical Christmas world where snowy nights sparkle, Santa's village glows with festive lights, and every corner is filled with holiday happiness.

**Winter Wonderland** is an interactive Christmas-themed website created to bring the joy, warmth and magic of Christmas to life.

Come and explore Santa's village, decorate a Christmas tree, discover festive stories and send your heartfelt wishes to Santa!

> ❄️ Christmas is coming! Let the magic begin. 🎅

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- Git
- Visual Studio Code

### 1. Clone the repository

```bash
git clone https://github.com/mohitkpani/winter-wonderland.git
```

### 2. Open the project

```bash
cd winter-wonderland
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL:

```text
http://localhost:5173
```

## 🏗️ Production Build

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## ☁️ Deployment with Vercel

This project is deployed using Vercel.

1. Push the project to GitHub.
2. Import the GitHub repository into Vercel.
3. Select Vite as the framework.
4. Set the build command to `npm run build`.
5. Set the output directory to `dist`.
6. Click Deploy.

Vercel can automatically deploy new changes when updates are pushed to the connected GitHub repository.
